# Legi's Adventure

The language of player progression and rewards in Legi's Adventure.

## Language

**Class**:
The player's primary weapon identity, including its starting attributes and class resources.
_Avoid_: Build, Path

**Tactic**:
A ranked combat adjustment chosen from random offers every five levels. Tactic ranks last for one run and can change attributes, attacks or class resources.
_Avoid_: Special Upgrade, Upgrade, Skill Rank

**Skill**:
A permanently discovered capability that can be equipped as the player's one Starting Skill at rank one. In the current game, choosing a Tactic unlocks its corresponding Skill.
_Avoid_: Ability, Starting Ability

**Equipment**:
A randomized reward chosen after clearing a guardian arena that adds attribute bonuses for the current run. Discovered Equipment names remain in the Equipment Journal.
_Avoid_: Relic, Gear

**Stats**:
The player's bounded combat attributes, including health, damage, speed and armor.
_Avoid_: Path Bonus

**Cosmetics**:
Permanent appearance choices earned through stage progression that do not change combat attributes.
_Avoid_: Equipment Color

**Run**:
One adventure beginning at stage one and ending in defeat, victory or a return to the menu.

**Stage**:
One arena within the twenty-stage adventure, cleared by defeating all enemy groups and resolving their drops.
